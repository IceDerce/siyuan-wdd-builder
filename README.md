# SiYuan Kernel Builder (Unlocked Edition)

Automated matrix build pipeline for SiYuan Note kernel with native WebDAV & VIP synchronization unlocked.

## Build Matrix
- **Linux amd64**: `SiYuan-Kernel` (for server deployments, e.g. `/opt/siyuan/kernel/`)
- **Windows amd64**: `SiYuan-Kernel.exe` (for desktop client override)

## Trigger
Go to **Actions** -> **Build Unlocked SiYuan Kernel** -> **Run workflow** -> Specify Tag (default: `v3.8.6`).
